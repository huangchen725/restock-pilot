## 关闭顺序与证据

1. **确认试点与权限**：完成上表，确认仅只读还是允许写入何种目标。没有这一步不操作商户后台。
2. **按真实页面适配**：复用当前受控工具、独立浏览器及授权隔离；固定站点/页面/动作/映射版本。验证会话失效、分页/结构变化和实际写请求被拒绝；不把通用点击或模型提示词当权限边界。
3. **只读两批实测**：在两个真实业务时间点取得完整批次，独立核对销售/库存/采购条款/在途及实际变化；记录来源时间、采集时间、时延、人工接管和失败。只有一次导出或历史公开数据不足以证明持续获取。
4. **真实数据驱动演示闭环**：无需手工搬运数据或点击生成，由定时检查更新原任务；人工仅批准最终可追溯版本，核对自建后台实际申请及 CSV/HTML，明确仍为演示写入。
5. **重放与故障**：同批重复、旧事件晚到、进程中断、来源过期/缺项以及未知单据必须保持防重和停写；结果以实际目标单据、批准及持久日志独立核对。
6. **结论**：由用户确认该试点、该字段/时间窗口与持续获取条件。满足 1–5 才能关闭 M5-0B 和 M5-4 的真实来源门槛；不扩大到其他平台。真实商家采购系统上线另行授权与验收，不把演示申请说成付款或到货。
